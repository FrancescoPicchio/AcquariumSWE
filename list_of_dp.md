# List of Design Pattern in the SWE course

## Structural

> **Definition**: a DP for organizing classes by making them more efficient and maintainable

- Adapter;
- Proxy;
- Composite;
- Bridge;
- Facade;
- DAO;

## Behavioral

> **Definition**: a DP for collaboration between objects.

- Observer;
- Decorator;
- Mediator;
- Visitor;
- Iterator;

## Creational

> **Definition**: a DP for assisting in creating objects, by giving guarantees on what is created, who creates what, and how it gets created.

- Singleton;
- Factory;
- Builder;
